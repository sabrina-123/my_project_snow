# TP — Tester, mesurer et automatiser ShopNow

## Contexte
Vous êtes une équipe QA/DevOps. Votre mission est de faire évoluer une suite de tests autour de ShopNow.

## Consignes
1. Forker le dépôt GitLab.
2. Créer une branche `feature/tests-<nom>`.
3. Écrire les tests sans supprimer les tests de référence.
4. Commiter régulièrement.
5. Ouvrir une Merge Request.
6. Vérifier le pipeline Jenkins.
7. Examiner le rapport SonarQube.

## Livrables
- Tests unitaires supplémentaires.
- Tests API supplémentaires.
- Tests Selenium E2E.
- Rapport de couverture.
- Corrections des problèmes identifiés par SonarQube.
- Pipeline Jenkins fonctionnel.

## Critères d'observation
- Pertinence des assertions.
- Gestion des cas nominaux et erreurs.
- Qualité des sélecteurs Selenium.
- Utilisation des attentes explicites.
- Lisibilité et maintenabilité.
- Intégration CI.
